## CS6460 — Module 1 (Honorlock)

Joyner quizzes punish near-misses (definitions + basic applications). **Layman** then **course voice**.

**Course shape.** Three parts: developing learning *technologies* → designing learning *experiences* → *measuring* learning. **Assessment** = this student’s grade/feedback. **Evaluation** = improve the tool/curriculum for the next cohort. FA26: quizzes 1/3/5, labs 2/4/6, one project. Pivot allowed. Module 0’s “each part is a project” is not the calendar. OMSHub / old syllabi are **wrong** for this term (no 60-paper phase; no pick-one Development/Content/Research track).

**Labs vs quizzes (Joyner Ed #16).** Labs **reinforce** the modules; they are not tests of the modules. Quizzes are **definitions + basic applications** — the terms you must not misuse in conversation. Pool **>1400** questions across lessons; two attempts by design (second quiz is not a near-copy). Project later: **build + teach + research** in one proposal, not one track. Implementation may use AI; proposal/milestones/report must defend choices with course principles.

**Mayer / load (primed now; full Mayer is Module 3).** Image Principle: instructor face on video usually does not raise learning. Coherence Principle: extras that carry no meaning can *hurt*. Cognitive load (Sweller): inherent difficulty / presentation mess / work of understanding. Split attention across face + slides + voice is a tax unless both streams are necessary.

**Constructivism (TIV).** Knowledge is built as a **mental model**, not copied. Piaget: assimilation, accommodation, disequilibrium. You cannot sentence-correct a misconception (Posner: dissatisfied → intelligible → plausible → more useful). Vygotsky: social first; **ZPD**; tool as more-knowledgeable other. **Scaffolding must fade.** Bjork **desirable difficulties**: hard in *content*, not UI. Kirschner, Sweller, Clark 2006: unguided discovery ≠ constructivism-as-theory; novices need guidance. Kapur **productive failure**: struggle, then explicit consolidation.

**Constructionism (TION).** Papert: think *by* building; **objects-to-think-with**; hard fun. Not the same as constructivism. Resnick: low floor, high ceiling, **wide walls**; Four P’s.

**Direct instruction.** Explicit, structured teaching + modeling + feedback. **Gradual release** (Pearson/Gallagher): I do / we do / you do — same arc as fading scaffolds. Not identical to lecturing; bad DI is “I tell, you do.” KSC 2006 + **worked example effect** (novices learn from worked examples) + **expertise reversal** (that advantage flips as skill grows). **lowercase di** = teacher-led teaching in general. **Capital-D Direct Instruction** = Engelmann/Becker scripted model, “faultless communication,” Project Follow Through.

**Behaviorism.** Learning = observable behavior change; ignore the black box. Classical conditioning (Pavlov): CS/US/CR; acquisition, extinction, generalization. Law of Effect (Thorndike) → operant (Skinner). **Reinforcement increases** behavior; **punishment decreases**. **Positive = add; negative = remove** (negative reinforcement is *not* punishment). Shaping / successive approximations. Learned helplessness. Rescorla–Wagner: learning from **prediction error**.

**Cognitivism.** Open the black box: perceive, encode, store, retrieve. Kept experimental rigor (not a return to introspection). Tolman latent learning / cognitive maps. Chomsky vs Skinner on language (poverty of the stimulus). Mind as information-processing. Ebbinghaus: **forgetting curve**, **spacing effect**. Atkinson–Shiffrin stores. Miller ~7±2, later ~4 **chunks**; expertise is chunking. Baddeley working memory: verbal vs visuospatial channels (why dual-channel multimedia can help).

**Human vs machine learning.** Psych/ed went behaviorism → cognitivism (outside then inside). AI went the other way (hand-coded rules → reward/training). Same road, opposite directions.

**Metacognition.** Thinking about thinking. Monitor (how is this going?) vs control (change strategy). Object level vs meta level (Nelson & Narens). Costs working memory; anxiety eats the budget for it. Teach it until it is cheap.

**Sociocultural.** Learning through participation in cultural practices, not a lone skull. Vygotsky: higher functions appear **twice** — first between people, then inside. ZPD is the mechanism of that move inward.

**Motivation.** Not a binary on/off. Direction + intensity; theories are tools. **Self-determination** (Deci/Ryan): autonomy, competence, relatedness — intrinsic vs controlled extrinsic. **Expectancy–value**: will I succeed × is it worth it. **Goal orientation / mindsets**: mastery vs performance; growth vs fixed (Dweck). **Attribution** (Weiner): what the learner blames (ability vs effort vs luck) shapes the next try. **Flow**: challenge matched to skill. Dark patterns: the same levers can manipulate.

**Ethics.** Students often **cannot opt out**. Two duties: **prevent harm** vs **ensure access**. Reich: toxic data vs EdTech Matthew effect.

**Traps.** No notes/AI/scratch/breaks on quizzes. You write prose. Ed, not Canvas inbox. Full calendar over Assignments tab.

## CS6795 — Lessons 1–3 + Thagard Ch. 1–4

No exam course. Weekly quizzes are MC, two attempts, **not** Honorlock. Lectures + Thagard *Mind* (2nd ed., 2005) are folded here. Cite `cs6795-cognitive-science/raw/reference-thagard-mind.pdf`.

**CRUM (Thagard’s name).** Computational-Representational Understanding of Mind: thinking = **representational structures** + **computational procedures** on them. Connectionism still counts. **Multifarious** (no one type is enough), **successful**, **incomplete** (needs brains + social — his Part II). Six approaches in order: logic, rules, concepts, analogies, images, connections.

**Explanation schema (every chapter).** Why this intelligent behavior? People have representations of type X. People have processes Y on them. Y applied to X produces the behavior.

**Five criteria (use these to compare approaches):** representational power; computational power (planning / decision / explanation, plus learning and language); psychological plausibility; neurological plausibility; practical applicability (education, design, intelligent systems, mental illness).

**Mind–computer–brain.** Program: data structures + algorithms = running programs. Mind: representations + procedures = thinking. Third analog = brain (especially connectionism). Serial vs parallel. Rough — not “the brain is a PC.”

**Marr’s three levels (lecture, not Thagard Ch. 1).** Computational = what problem. Algorithmic = algorithms + data structures. Implementation = neurons / silicon. Do not answer a “what is computed?” question with neurotransmitters. Thagard organizes by CRUM + six types + five criteria instead.

**Logic (Ch. 2).** Representations ≈ predicate-logic sentences; **deductive and inductive** procedures. **Modus ponens.** **Abduction** (Peirce): hypothesize in order to *explain* (Frank didn’t show → maybe sick). **Induction:** narrow = generalize from instances; broad = any uncertain inference (abduction counts). **Bayes** for P(h|e). Logic is a strong tool; Thagard is not sure it is the *core* of human thinking. Lecture: Holmes clip = abduction from signs.

**Probability / Monty Hall (lecture).** If we ran probability we’d switch (~2/3); most people stick — so probability may not be what the mind uses. Still huge in AI. **Bounded rationality (Simon):** incomplete info + limited compute → **satisficing**.

**Rules (Ch. 3 + lecture).** Mental rules + **search** of a solution space + procedures that **form new rules**. Newell/Simon, ACT, SOAR. Same if–then *look* as logic, not the same as running modus ponens. Lecture: **domain/world** vs **control/strategy** (control is often tacit). **Heuristics** = rules of thumb (availability heuristic). **Power law of practice** (Thagard).

**Concepts (Ch. 4 + lecture).** Drop **classical** strict definitions. Concepts ≈ **typical features**; apply by **approximate match**. **Schemas/scripts** = bigger feature-bundles. Slots, kind/part hierarchies; spreading activation, matching, **inheritance**. Lecture types that still trick MC: **axiomatic** / **prototypical** / **exemplar** / **qualia**. **Percept** = this red light; concept = the class **red** that indexes stop.

**Course aim (Welcome).** Join the conversation; read a paper; analyze a problem as cog-sci. Thagard is the map of representational theories.

**Traps.** 12 quizzes, not 10. No public GitHub. IEEE on writeups. Open Ed slides yourself. Optional YouTubes are extras.
